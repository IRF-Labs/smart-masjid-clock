## One-time: enable GitHub Pages

GitHub Actions cannot turn Pages on by itself. Do this once:

1. Open https://github.com/Engrirfaan/smart-masjid-clock/settings/pages
2. Under **Build and deployment → Source**, choose either:
   - **Deploy from a branch** → Branch `main` → folder `/ (root)` → **Save**, or
   - **GitHub Actions** → Save (then re-run the “Deploy GitHub Pages” workflow)
3. Wait about a minute, then check https://engrirfaan.github.io/smart-masjid-clock/privacy/

Until then the privacy page is still available as raw HTML:
https://raw.githubusercontent.com/Engrirfaan/smart-masjid-clock/main/privacy/index.html
